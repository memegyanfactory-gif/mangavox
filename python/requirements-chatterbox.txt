# (Python 3.11): its pins (torch 2.6, transformers 5.2, numpy<2) clash with Kokoro's.
# `python chatterbox_tts.py install` (or `kokoro_tts.py install-engine chatterbox`) builds it
# in <data>/engines/chatterbox with uv; this file mirrors what it installs (DEPS in
# chatterbox_tts.py), for a manual setup:
#
#   uv venv --seed --python 3.11 <data>/engines/chatterbox
#   uv pip install --python <venv python> torch==2.6.0 torchaudio==2.6.0 --index-url https://download.pytorch.org/whl/cu124
#       (CPU only: --index-url https://download.pytorch.org/whl/cpu)
#   uv pip install --python <venv python> -r requirements-chatterbox.txt
#   uv pip install --python <venv python> chatterbox-tts==0.1.7 --no-deps
#
# Weights (3.2 GB) go to <data>/models/chatterbox (see WEIGHTS in chatterbox_tts.py).
